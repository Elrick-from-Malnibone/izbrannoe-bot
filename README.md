📂 Избранное 2.0
Telegram-бот, который заменяет стандартное «Избранное» на структурированное хранилище с папками (топиками).

Проблема: В родном Избранном одна сплошная свалка.
Решение: Бот создает папки прямо в чате. Все файлы и текст хранятся на серверах Telegram — ваш сервер не нагружается.

🚀 Попробовать
Просто запустите бота и нажмите кнопку «📁 Создать папку»:

Код полностью открыт. Чтобы развернуть локально:

Создайте .env с вашим BOT_TOKEN и ADMIN_ID

Запустите python main.py
